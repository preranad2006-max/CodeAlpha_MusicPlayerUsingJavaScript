# 🎵 Pulse Player – Music Player Using JavaScript

Pulse Player is a modern, responsive music player built using **HTML, CSS, and Vanilla JavaScript**. It provides an interactive interface for playing songs with essential audio controls, playlist management, progress tracking, volume control, and autoplay.

## 🚀 Features

- ▶️ Play and pause music
- ⏮️ Previous and next song controls
- 🎶 Playlist with 8 tracks
- 🖼️ Dynamic album artwork
- 👤 Displays song title and artist
- ⏱️ Real-time playback duration
- 📊 Interactive progress/seek bar
- 🔊 Volume control
- 🔁 Autoplay support
- ✨ Smooth hover effects and transitions
- 📱 Responsive design for desktop, tablet, and mobile
- 🎨 Modern dark-themed user interface
- 💾 Local audio files for playback

## 🛠️ Technologies Used

- **HTML5** – Structure and layout
- **CSS3** – Styling, animations, transitions, and responsive design
- **JavaScript** – Audio controls and dynamic playlist functionality
- **HTML5 Audio API** – Music playback and audio management
- **SVG** – Album artwork and project icon

## ⚙️ How It Works

The project uses a JavaScript array containing the following song information:

- 🎵 Song title
- 👤 Artist name
- 🎧 Audio file
- 🖼️ Album artwork
- ⏱️ Duration

JavaScript dynamically loads the selected song and updates the player interface.

### 🎧 HTML5 Audio API

The HTML5 Audio API handles:

- ▶️ Playing and pausing songs
- ⏭️ Moving between tracks
- ⏱️ Tracking playback time
- 📍 Seeking through a song
- 🔊 Adjusting volume
- 🔁 Detecting when a song ends

 ## 🎮 Controls

The music player provides the following controls:

- ▶️ **Play** – Starts the current song
- ⏸️ **Pause** – Pauses the current song
- ⏮️ **Previous** – Plays the previous track
- ⏭️ **Next** – Plays the next track
- 📊 **Progress Bar** – Seeks to a specific position in the song
- 🔊 **Volume** – Adjusts the playback volume
- 🔁 **Autoplay** – Automatically plays the next track

## 📱 Responsive Design
